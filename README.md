## Firebase Hosting (Flutter Web)

Safe deploy command for this repository:

```bash
firebase deploy --only hosting:app
```

Do **not** run `firebase deploy --only hosting` from this repo.

`app.swapstash.net` is the Flutter Web site (`swapstash-app-49199`).
`swapstash.net` is the marketing site and is **not** deployed from here.

See [docs/FIREBASE_HOSTING.md](docs/FIREBASE_HOSTING.md).
